## Task

Write the exercises of the section below (spec 07, part 6, and spec 10.4).

1. Give each exercise a grade: (E) easy, (M) medium or (L) Lean.
2. For each (L) exercise, write the statement file and the solution file in tamnd/mathlib-lean. The statement has `sorry` in place of the proof. The solution must build with `lake build`.
3. Do not change a statement after its hash is in the record. The hash check of spec 10.4 fails on a changed statement.
4. Write the text of the solutions for the solutions appendix.
5. Write new exercises (decision Q-20 of spec 16). You can adapt an exercise from a source with an open licence, such as MIL (CC BY 4.0). Then give a credit line with the source and its licence below the exercise. Do not copy an exercise from a book with a closed licence.
